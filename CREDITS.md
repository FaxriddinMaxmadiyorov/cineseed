If you reuse this project, keep these notices, and note that a few items carry NonCommercial terms (marked NC) that would have to be replaced before any commercial use.

## Software

Ruby on Rails, Turbo and Stimulus (MIT), Faker (MIT), zip_kit (MIT), Puma (BSD-3-Clause). Rendering is done by FFmpeg with libass and x264 (LGPL/GPL). The audio library was analysed once with librosa (ISC) when it was built.
